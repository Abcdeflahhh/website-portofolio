# Personal Branding Portfolio — Aflah Athallah Tamam Kapukong

Website portofolio pribadi modern dan profesional dengan estetika **Midnight Blue & Silver**, dirancang khusus untuk merepresentasikan profil, keahlian, dan penugasan akademik **Aflah Athallah Tamam Kapukong** (Mahasiswa S1 Teknik Informatika, Universitas Pelita Bangsa).

---

## 🌟 Fitur Utama Website

- **Desain Modern Luxury:** Palet warna Midnight Blue (`#0B1220`), Deep Navy (`#111C30`), dan aksen Silver (`#C5CCD6`) yang elegan, bersih, dan berwibawa.
- **Hero Section dengan Foto Profil Asli:** Dilengkapi foto profesional terverifikasi, ringkasan profil, dan tombol akses cepat dokumen.
- **Interactive Skills Explorer:** Filter interaktif 6 kategori keterampilan (Office & Admin, Data Processing, Programming & Web, Database, Tools, dan Professional Skills) berbasis penugasan nyata.
- **Academic Project Showcase & Detail Modal:** 6 studi kasus penugasan perkuliahan dan latihan mandiri dengan jendela modal interaktif dan penjelasan arsitektur kode.
- **Document Center (CV & Resume):** Tautan langsung untuk melihat (`target="_blank"`) dan mengunduh (`download`) file resmi `cv-aflah.pdf` dan `resume-aflah.pdf`.
- **Formulir Kontak Terintegrasi:** Jembatan email langsung berbasis `mailto:` serta tombol salin email instan ke clipboard dengan indikator status.
- **Aksesibilitas & Performa Tinggi:** Mendukung navigasi keyboard (`:focus-visible`), kepatuhan `@media (prefers-reduced-motion: reduce)`, dan dibangun 100% menggunakan Vanilla Web Stack tanpa dependensi eksternal berat.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur semantik, aksesibilitas ARIA, metadata Open Graph & SEO.
- **CSS3:** Custom Properties (CSS Variables), CSS Grid & Flexbox responsif, keyframe animations, dan ambient glassmorphism.
- **JavaScript (ES6+):** Vanilla JavaScript murni untuk kanvas partikel geometris, filter tab dinamis, scroll progress bar, back-to-top, dan modal controller.

## 🚀 Panduan Publikasi ke GitHub Pages

Website ini bersifat statis murni sehingga dapat langsung di-hosting gratis melalui **GitHub Pages**:

1. Buat repositori baru di akun GitHub Anda (misalnya `portfolio` atau `<username>.github.io`).
2. Hubungkan repositori lokal dan push branch `main`:
   ```bash
   git remote add origin https://github.com/<username>/<nama-repo>.git
   git push -u origin main
   ```
3. Buka repositori Anda di GitHub, lalu masuk ke menu **Settings** > **Pages**.
4. Pada bagian **Build and deployment** > **Branch**:
   - Pilih branch `main` dan folder `/ (root)`.
   - Klik tombol **Save**.
5. Tunggu sekitar 1–2 menit, website Anda akan langsung aktif secara publik dengan URL:
   `https://<username>.github.io/<nama-repo>/`
